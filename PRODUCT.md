# GINHAWA product website

## Platform
Responsive static web. Independent of the Flutter and administration projects.

## Purpose and audience
Introduce GINHAWA to tertiary students and guidance personnel. GINHAWA is a BSCS capstone developed for students at STI College Caloocan. The user confirms project validation by STI College Caloocan Guidance Associates. This is distinct from clinical validation or institutional deployment approval. No public-release or store-availability claim.

## Confirmed capabilities
Stress and distress self-assessments; daily mood check-ins; general recommendations; personalized AI guidance; self-paced activity pages; history; consultation requests. A separate administrative system supports monitoring, analytics, and consultation management. All website demonstrations are synthetic and disconnected from accounts.

## Constraints
Wellbeing support and self-awareness, never diagnosis or treatment. No AI calls, Firebase SDK, database, authentication, analytics, trackers, or actual student records. Existing applications remain untouched. Reuse the application fonts and Chika artwork. Reduced motion, keyboard access, and responsive layouts are required.

## Primary action
Introduce the application through a cinematic interactive screenshot gallery and encourage Android downloads. Until a verified public APK URL is configured, show an honest coming-soon state. No public registration or invented download destination. The user authorizes publishing the app support email and verified NCMH support contact in the shared footer and Support Resources.

## Stack
Astro, static output, plain CSS and small browser scripts. Vercel deployment instructions; no deployment requested. Node 24+.
